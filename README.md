# PoupeMais

Controle financeiro pessoal com armazenamento no navegador. Os dados não são sincronizados entre aparelhos e podem ser perdidos ao limpar os dados do navegador. Use Exportar cópia para manter backups e Importar cópia para restaurá-los. A importação substitui os lançamentos existentes.

A publicação é feita pelo GitHub Pages a partir da branch principal. O aplicativo não usa Supabase ou banco remoto.
